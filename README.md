# Haptik

**Nudge**: touch-only guidance for blind and DeafBlind people. Two wrist-worn Joy-Cons buzz to steer
the wearer to a saved place, to their Waymo (right up to its door handle), or to a thing they ask
for ("water bottle"), then steer their hand onto the handle or the thing, and stop them for
obstacles along the way. No sound in, no sound out.

Everything lives in [`nudge/`](nudge/). Start with **[nudge/README.md](nudge/README.md)**: what you
need, how to build and run it step by step, how to test it, and how every part works.

```
git clone https://github.com/Akhileshreddym/Haptik.git
cd Haptik/nudge
npm install
npm start
```
