# Paradise

**Paradise**: touch-only guidance for blind and DeafBlind people. Two wrist-worn Joy-Cons buzz to
steer the wearer to a saved place (along sidewalks, by an OpenStreetMap walking route), to their
Waymo (right up to its door handle), or to a thing they ask for ("water bottle"), then steer their
hand onto the handle or the thing, and stop them for obstacles along the way. When the thing isn't
in view, it turns them round the room to look, and only if that finds nothing asks an AI (Gemini)
where to go look next. No sound in, no sound out.

Everything lives in [`paradise/`](paradise/). Start with
**[paradise/README.md](paradise/README.md)**: what you need, how to build and run it step by step,
how to test it, and how every part works.

```
git clone https://github.com/Akhileshreddym/Paradise.git
cd Paradise/paradise
npm install
npm start
```
